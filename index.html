    島の広場が、ねばねばの「スミ」で汚されてしまった！
    主人公プカのひょうたんポンプで洗い流し、14個のヒカリ石を集めよう。

    キーボード＋マウスゲームパッド

    視点マウス（ホイールで距離）右スティック
    ジャンプSpaceA
    ホバー空中で Space 長押し / Shift / 右クリック空中で A 長押し / LT
    水をかける左クリック / FRT / X
    ポーズEsc / PSTART
    • 水は海や噴水に入ると補給できる。
    • 水をかける向きは、視点の上下で変えられる。見上げれば遠くまで届く。
    • スミの上は足を取られる。スミボウは水をかけるか、上から踏んでやっつけよう。
    • ヒカリ石が集まると、町の建物がスミのかたまりに覆われる。洗い流すと壁に入口のしるしが現れ、飛びこむと別のエリアへ行ける。
